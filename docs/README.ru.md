## Что такое Techne

Techne собирает повседневные локальные задачи фронтенд-разработки в одном окне: состояние проектов и Git, запущенные dev-серверы, отдельные экземпляры Chrome для отладки, сборку мини-приложений, развёртывание Android и журналы команд.

## Состояние проекта

> **Активная разработка**

Основные рабочие процессы реализованы. Для каждого push и pull request запускаются тесты автоматизации, `TechneTests` и неподписанная сборка Release. Текущий манифест настроен на публикацию версии `0.1.0-beta.1` после успешного прохождения CI в main.

## Платформа

| Параметр | Значение |
|---|---|
| Минимальная версия macOS | macOS 26.0 Tahoe |
| Сборка из исходников | macOS 26.0+ и Xcode 26+ |
| Архитектура выпуска | Apple Silicon (`arm64`) |
| Тип приложения | Нативное несандбоксированное приложение macOS с доступом из строки меню |
| Распространение | DMG в GitHub Releases, подписанный сертификатом Apple Development, но не нотариально заверенный Apple |

## Установка и выпуски

Каждый выпуск GitHub содержит один файл `Techne-<версия>.dmg`. Откройте DMG и перетащите `Techne.app` в папку `Applications`. Из-за отсутствия нотариального заверения Apple перед первым запуском выполните:

```bash
sudo xattr -rd com.apple.quarantine /Applications/Techne.app
```

Манифест выпуска находится в [`Config/Release/manifest.json`](../Config/Release/manifest.json). Поддерживаются версии `x.y.z`, `x.y.z-alpha.n` и `x.y.z-beta.n`. Суффикс Alpha или Beta используется в Release, теге, DMG и [CHANGELOG.md](../CHANGELOG.md), а `CFBundleShortVersionString` приложения получает только числовую часть `x.y.z`.

## Основные решения

- Проекты объединяют управление Git, обнаружение локальных dev-серверов и экземпляры Chrome для отладки.
- Каждый отладочный экземпляр Chrome использует отдельный временный профиль; после закрытия окна Techne удаляет этот профиль.
- Для разных типов проектов можно сохранять шаблоны команд запуска, сборки, очистки, установки и остановки.
- Ключевые операции — запуск, остановка, сборка, развёртывание и переключение веток — сохраняются в журнале, который можно фильтровать по категориям.

## Расположение данных

Состояние приложения хранится в:

```bash
~/Library/Application Support/studio.slippindylan.Techne/
```

Временные данные экземпляров браузера хранятся в:

```bash
~/.techne-browsers/
```
