## Что делает Techne

Techne предназначен для разработчиков, которые постоянно возвращаются к одним и тем же локальным проектам. Явно добавьте проект один раз, а затем проверяйте ветку Git и рабочее дерево, запускайте команды, действительно объявленные в репозитории, находите его dev-сервер или открывайте браузер. Сканирование портов только связывает серверы с уже управляемыми проектами и не добавляет неизвестные проекты автоматически.

Основные сценарии работы с проектами:

- Web-проекты и собираемые мини-приложения анализируются по манифестам и скриптам; перед запуском Techne может подготовить недостающие зависимости.
- Нативные мини-приложения WeChat открываются и закрываются через CLI WeChat DevTools без команды запуска Shell.
- В Android-развёртывании можно выбрать APK, найти подключённое устройство, установить APK через ADB и посмотреть вывод команд.

## Установка

### Homebrew

```bash
brew tap slippindylan/tap
brew trust --tap slippindylan/tap
brew install --cask techne@beta
```

### DMG

Скачайте DMG со страницы [Techne Releases](https://github.com/SlippinDylan/Techne/releases), откройте его и перетащите `Techne.app` в `Applications`. Опубликованные DMG предназначены для Mac с Apple Silicon.

Текущие релизы подписаны сертификатом Apple Development, но не нотариально заверены Apple. Поэтому macOS может заблокировать первый запуск или сообщить, что разработчика невозможно проверить. Если DMG получен с официальной страницы Releases, приложение перенесено в `Applications` и вы решили продолжить, снимите атрибут карантина:

```bash
sudo xattr -rd com.apple.quarantine /Applications/Techne.app
```

## Быстрый старт

1. Откройте Techne, явно добавьте локальный проект и выберите проект с dev-сервисом или мини-приложение WeChat.
2. Techne читает реальные манифесты, скрипты, сведения о менеджере пакетов и lock-файлы. Если исполняемый проект определить нельзя, Techne отклоняет каталог, а не придумывает команду.
3. Запустите проект. Для npm, pnpm, Yarn или Bun недостающие зависимости устанавливаются автоматически; после изменения манифеста или lock-файла подготовка выполняется снова. Команды запускаются через настроенный zsh, Bash или fish в режиме login shell.
4. При необходимости остановите или перезапустите проект. Обычная остановка и перезапуск не очищают кэш сборки и не закрывают управляемые окна браузера.
5. Для Web-проекта откройте найденный сервер в установленном браузере.
6. Для Android откройте экран развёртывания, подключите устройство, выберите APK и запустите развёртывание.

### Браузеры и отдельные профили

Techne обнаруживает установленные Safari, Google Chrome, Chrome Beta, Chromium, Microsoft Edge, Brave и Arc. Safari открывает адрес обычным способом. Chrome, Chrome Beta, Chromium, Edge, Brave и Arc основаны на Chromium: для каждого управляемого экземпляра Techne создаёт отдельный каталог профиля, новое окно и назначает свободный порт удалённой отладки, начиная с `9222`. Файлы cookie и данные сайтов не смешиваются с обычным профилем браузера или другими управляемыми экземплярами.

### Web-проекты и мини-приложения WeChat

Для проектов на основе Shell Techne запускает только скрипты, действительно объявленные в репозитории. Он распознаёт распространённые Web dev-скрипты и цели WeChat для Taro, UniApp и Mpx, а также поддерживает npm, pnpm, Yarn и Bun. Зависимости устанавливаются в найденном корне workspace, а dev-команда по-прежнему выполняется в выбранном каталоге проекта.

Нативные мини-приложения с корректным `project.config.json` в корне открываются, закрываются и восстанавливают наблюдение за файлами через установленный CLI WeChat DevTools. Для собираемых мини-приложений восстановление использует сгенерированный каталог проекта DevTools, когда он появляется. Techne не включает Node.js, менеджеры пакетов, CLI фреймворков или WeChat DevTools: нужные среда выполнения и инструменты должны быть установлены и доступны из login shell.

### Развёртывание Android APK

Установите Android SDK Platform-Tools, чтобы `adb` был доступен в `PATH`, подключите Android-устройство с включённой USB-отладкой и установите Android SDK Build Tools. Techne использует `aapt2` или `aapt` для чтения имени пакета APK: сначала ищет в `PATH`, затем в `~/Library/Android/sdk/build-tools`.

## Требования

| Что нужно | Подробнее |
|---|---|
| macOS | macOS 26 Tahoe или новее |
| Оборудование | Опубликованный DMG только для Apple Silicon |
| Работа с Git | `git` в `PATH` для статуса и операций с ветками |
| Связывание управляемых серверов | Системный `lsof`; Techne сканирует слушающие TCP-порты 3000–9999 и связывает их только с уже добавленными проектами |
| Запуск браузера | Хотя бы один поддерживаемый установленный браузер |
| Web и собираемые мини-приложения | Node.js, менеджер пакетов и инструменты фреймворка доступны из login shell; зависимости проекта может подготовить Techne |
| Нативные мини-приложения WeChat | WeChat DevTools установлен и содержит CLI внутри пакета приложения |
| Android-развёртывание | `adb`, Android SDK Build Tools (`aapt2` или `aapt`) и устройство с включённой USB-отладкой |

## Где хранятся данные

Записи проектов, настройки команд и журналы хранятся в:

```bash
~/Library/Application Support/studio.slippindylan.Techne/
```

Profile и файлы отслеживания управляемых экземпляров Chromium хранятся в:

```bash
~/.techne-browsers/
```

## Сборка из исходников

Нужны macOS 26 или новее и Xcode 26 или новее. Клонируйте репозиторий, откройте `Techne.xcodeproj` в Xcode и запустите схему `Techne`. В Terminal можно выполнить:

```bash
git clone https://github.com/SlippinDylan/Techne.git
cd Techne
xcodebuild -project Techne.xcodeproj -scheme Techne -configuration Debug build
```

Внешние инструменты выше нужны только для функций, которые их используют.
